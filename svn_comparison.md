1. Почему в Git ветвление "дешёвое", а в SVN - "дорогое"?

В Git ветка - это просто лёгкий указатель на коммит (файл с хешем), создаётся за доли секунды. В SVN ветка - это полноценная копия директории в репозитории, которая создаётся долго и требует места, хотя внутри и использует ссылки.

2. Можно ли в SVN сделать коммит без интернета? Почему?

Нет, SVN - клиент-серверная система, вся история хранится только на сервере. Локально у тебя только рабочая копия файлов, без базы изменений, поэтому зафиксировать изменения можно только отправив их на сервер.

3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?

Когда проект содержит много тяжёлых бинарных файлов, когда нужен частичный checkout огромного репозитория, или в компаниях с централизованным контролем, где проще администрировать один сервер.
